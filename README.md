# 계산기 (Calculator)

파이썬으로 만든 간단한 계산기입니다.

## 기능

- 더하기 (add)
- 빼기 (subtract)
- 곱하기 (multiply)
- 나누기 (divide)

## 사용 방법

```python
from calculator import add, subtract, multiply, divide

print(add(3, 5))       # 8
print(subtract(10, 4)) # 6
print(multiply(2, 6))  # 12
print(divide(9, 3))    # 3.0
```
